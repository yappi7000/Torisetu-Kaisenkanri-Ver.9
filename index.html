1このアプリって何？

MNP（携帯乗り換え）で発生する 💴キャッシュバック・💸手数料や解約金・💳毎月の固定費・📅オプション解除の期限 を回線ごとにまとめて管理して、「結局この回線でいくら儲かった／損したか」を一目でわかるようにするアプリです✨

4「手残り」って何？💰最重要

このアプリでいちばん大事な数字が「手残り」です。

手残り　＝　💴CB合計　－　💸支出合計　－　💳月額固定費の累計

回線カードや編集画面に、この計算結果が自動で出ます。月額固定費は契約日から今日（解約済なら解約日）までの月数ぶん、自動で引き算されるので、放っておいても今いくら残っているかがすぐわかります👀

💳 月額固定費が月ごとに違う場合

「初月無料→2ヶ月目から割引→4ヶ月目以降は定価」のようなキャリアの割引パターンにも対応しています。

  1. 月額固定費の項目で「月ごとに変わる」を選ぶ
  2. 初月／2ヶ月目／3ヶ月目／4ヶ月目以降　の4つの金額を入力
  3. あとは自動で毎月の単価を当てはめて合計してくれます🧮
📌 毎月同額のキャリアなら「毎月同額」のままでOK。今まで通り1つの金額を入れるだけです。

5取引（CB・支出）を追加する💸

登録済みの回線をタップして編集画面を開くと、下の方に「取引履歴」があります。

  1. 「＋ 取引を追加」をタップ
  2. 収入（💴もらったお金）か支出（💸払ったお金）かを選ぶ
  3. 金額・日付・メモ（任意）を入れて保存

手数料や解約金など、CB以外のお金の動きはここに記録していきます📒

6🔔 オプション解除の通知設定

MNPで一番やりがちな失敗が「オプションの解除忘れ」です😱 これを防ぐのがトップ画面の🔔ベルアイコンです。

  1. トップ画面の 🔔 をタップ
  2. 右下の＋ボタンで新しい予定を追加
  3. 対象回線・種類（オプション解除／維持期間終了／その他）・期日・通知タイミングを入力して保存
🔴 赤期限切れ（今すぐ対応）
🟡 黄期限まで7日以内
🔔バッジ期限が近い予定の件数を表示

⏰ スマホに通知を届けたい場合

設定画面（⚙️）の「解除リマインダーをカレンダーに追加」から、通知つきファイル（ics）をダウンロードできます。これをスマホの標準カレンダーアプリに取り込むと、設定した日数前に端末の通知が届きます📲（LINE通知は今後追加予定）

9📶 毎月の稼働確認NEW

回線は「使っていないと止められる」ことがあります。そこで、月に1回、通話とデータを使って動いているかを確認して、その記録をこのアプリに残せます📝 確認し忘れた回線はバッジで知らせます。

📍 開き方

  1. トップ画面の 📶ボタン をタップ（設定の「毎月の稼働確認」からも開けます）
  2. 上の「‹ ›」で月を切り替え。確認済み／対象回線 の件数とバーで進み具合がわかります
  3. 一覧は「未確認」「確認済み」「すべて」で絞り込めます
📌 📶ボタンの赤いバッジは「今月まだ確認していない回線の数」です。0になると消えます。

✅ 確認を記録する（かんたん）

一覧の回線をタップするだけで、今日の日付で確認済みになります。もう一度タップすると未確認に戻ります。回線カード（トップ画面）にも「📶 未確認」か「📶 今月✓ 10/16 📞🌐」のように出ます。

📞🌐 通話・データ・メモを詳しく残す

回線ごとに、日付・通話・データ を分けて記録できます。

  1. 回線の編集画面を開き、下の方の「📶 稼働確認」へ
  2. 月のチップをタップするか「＋ ○月の稼働を記録」をタップ
  3. 日付を入れ、📞通話 と 🌐データ のうち実際に使った方をタップして色をつける（もう一度タップで解除）
  4. 必要ならメモを書いて保存
📞通話 ✓その月に通話の確認をした
🌐データ ✓その月にデータ通信の確認をした
－未実施（古いVer.9.2までの記録は、通話・データが「－」で表示されます）
直近の稼働編集画面の上に、いちばん新しい確認の日付・通話・データ・メモが出ます
⚠️ 通話・データ・メモを入れた月は、誤タップで消えないよう、タップすると詳細画面が開く作りです。消したい時は詳細画面の「取り消す」から行います。

🧮 どの回線が対象？

契約日が入っている契約した月から対象になります（契約日が空の回線は対象外）
運用中・解約予定毎月対象
解約済解約日の前の月までが対象。解約日が空だと対象外

🚀 まとめて確認済みにする

全部の回線を実際に確認できた月は、「未確認○件をまとめて確認済みにする」ボタンで未確認ぶんを今日付けで一括登録できます。実際に確認した回線だけに使ってね。

10☁️ PCとスマホでデータを同期するNEW

初期状態では、データはその端末のブラウザの中だけに保存されます。PCで入力してもスマホには出ません。無料のFirebase（Googleのサービス）でつなぐと、どちらで入力しても同じデータになります🔄

⚠️ 先に必ず読んでね：つなぐと、Firebase側にデータがある場合はそれが優先され、その端末のデータが上書きされます。上書き事故を避けるため、必ず先に「データエクスポート」でバックアップを取ってください。

① Firebaseの準備（初回のみ・約10分）

  1. Firebaseコンソール（console.firebase.google.com）にGoogleアカウントでログインし、プロジェクトを新規作成
  2. 左メニュー「構築 → Realtime Database」でデータベースを作成。場所は近いもの（シンガポールなど）でOK
  3. 「ルール」タブを開き、中身を下のものに差し替えて「公開」を押す
  4. 左上の⚙️ →「プロジェクトの設定」→「全般」→ 一番下の「マイアプリ」で、ウェブアプリ（</>）を追加（ニックネームは何でもOK、Hostingは不要）
  5. 表示された firebaseConfig を丸ごとコピー（const firebaseConfig = {…}; のままOK。databaseURL の行が入っているか確認）
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
💡 ルールが初期のままだと、接続時に「Permission denied」のエラーになります。上のルールに差し替えて公開すれば直ります。

② PC（データが入っている方）から先につなぐ

  1. 設定 → データエクスポートでバックアップを保存
  2. 設定 → ☁️クラウド同期設定を開く
  3. コピーした firebaseConfig を貼り付けて「接続」をタップ
  4. 状態が「🟢 同期中」になればOK。Firebaseにまだデータが無ければ、PCのデータがそのままアップロードされます

③ スマホをつなぐ

  1. スマホでも同じ github.io のURL を開く（古い表示が残る時は、ブラウザを閉じて開き直す）
  2. （スマホに入力済みのデータがあれば、先にエクスポート）
  3. 設定 → ☁️クラウド同期設定に、PCと同じ firebaseConfig を貼って「接続」
  4. PCのデータが読み込まれて、同じ画面になります🎉

🔧 つながった後

🔄 今すぐ手動で再取得反映されない時に押すと、Firebaseの最新データを取り直します
解除その端末だけローカル保存に戻します（データは消えません）
同期される範囲回線・キャリア・契約者・使用者・予約番号・予定、稼働確認の記録もすべて
💡 テストモードのルールは「誰でも読み書き可能」です。databaseURLを他人に教えなければ実用上は問題ありません。URLやfirebaseConfigはSNSなどに載せないでね。

11💾 バックアップと復元

⬆️ バックアップを取る

設定 →「データエクスポート」で、JSONファイルが保存されます。回線・キャリア・契約者・使用者・予約番号・予定（解除管理）がまとめて入ります（Ver.9.3から「予定」も含まれるようになりました）。

⬇️ 復元する

  1. 設定 →「データインポート（バックアップ復元）」を開く
  2. 保存したJSONを選んで読み込む
  3. クラウド同期をオンにしている時は、復元したデータが他の端末にも反映されます
💡 古いバックアップに「予定」が入っていない場合は、今ある予定はそのまま残ります。
⚠️ 同期中は、どの端末で復元・上書きしても全端末のデータが入れ替わります。バックアップは、端末を新しくつなぐ前・大きな変更をする前に取る習慣にしてね。

12困ったときのチェックリスト✅

キャリアが選択肢に出てこない
キャリア選択欄の「＋ 新規追加」からその場で作成できます。
手残りがマイナスになっている
月額固定費の入れすぎ・CB未入力の可能性があります。編集画面の内訳ボックスを確認してください。
通知が来ない
カレンダーアプリへのics取り込みが必要です（6章を参照）。
📶ボタンや稼働確認が画面に出ない
古いページが表示されています。ブラウザを閉じて開き直す、またはページを再読み込みしてください。
稼働確認の対象に回線が出ない
契約日が空、または解約済で解約日が空の回線は対象外です。編集画面で日付を入れてください（9章）。
接続したら「Permission denied」と出る
FirebaseのRealtime Databaseの「ルール」が読み書き禁止になっています。10章の①のルールに差し替えて「公開」を押してください。
スマホにデータが反映されない
スマホ側でも同じ firebaseConfig を貼って「接続」を押す必要があります。接続済みなら「今すぐ手動で再取得」を試してください。
接続したらデータが古いものに入れ替わった
Firebase側に古いデータが先に入っていたためです。バックアップのJSONを「データインポート」で読み込めば戻せます。つなぐ前のエクスポートが命綱です。
データが消えないか心配
設定の「データエクスポート」で定期的にバックアップしましょう💾
